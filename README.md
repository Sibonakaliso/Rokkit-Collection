# Rokkit Collection

A custom WordPress eCommerce website developed as part of a Junior PHP / WordPress Developer technical assessment.

## Project Overview

Rookit Collection is a simple online clothing and accessories store built using WordPress, WooCommerce, PHP, HTML, CSS and JavaScript.

The project uses a custom WordPress theme without any page builders.

## Features

- Responsive homepage with hero and About sections
- Three featured WooCommerce products
- Product catalogue and individual product pages
- Customer registration and login
- Customer account dashboard and order history
- Shopping cart and checkout
- Direct Bank Transfer payment option
- Custom estimated delivery message using a WooCommerce PHP hook
- Responsive mobile navigation with a hamburger menu

## Technologies Used

- WordPress: 7.1.3
- PHP: 8.2.29
- WooCommerce
- MySQL

- JavaScript
- Git and GitHub

## Installation

1. Install WordPress.
2. Install and activate WooCommerce.
3. Download or clone this repository.
4. Copy the `rookit-collection-theme` folder into `wp-content/themes/`.
5. Activate Rookit Collection under Appearance → Themes.
6. Configure WooCommerce store settings and set the currency to South African Rand (ZAR).
7. Create the Shop, Cart, Checkout and My Account pages if they have not been generated automatically.
8. Add the required products and mark three as featured.
9. Enable customer registration and Direct Bank Transfer.
10. Open the homepage to view the website.

## Assumptions

- The website is intended for demonstration and assessment purposes.
- Product information and images are sample content.
- Direct Bank Transfer is used instead of a payment gateway.
- WordPress and WooCommerce must be installed separately.
